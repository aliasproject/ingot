How Alios CLI Works

1

Install in One Command

Download the binary and run it. Alios CLI installs itself to /usr/local/bin, sets up GitHub authentication, and starts the shared DNS, Caddy, and Mailpit services - no separate setup steps.

2

Start Any Project

cd into a project and run alios start. It detects your PHP version, an existing Dockerfile, or a WordPress install automatically - asked once, remembered forever.

$

alios start

✓ https://myproject.test

3

HTTPS Out of the Box

A locally-trusted CA and per-project certificates are generated automatically, and Caddy routes *.test domains straight to your container - no manual vhost files, no hand-edited hosts file.

4

Ship With Confidence

The same prebuilt-image or custom-Dockerfile choice you make locally is the choice Alios makes in production - what runs on your machine is what runs live.

Simple Commands, Powerful Results 

# Install and set up your entire development environment
$ ./alios

# Start a project
$ alios start

# Check status
$ alios status

# Work with the running container
$ alios logs
$ alios exec composer install
$ alios shell

# Stop or restart
$ alios stop
$ alios restart
