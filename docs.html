Devbox Documentation

Welcome to Devbox, the ultimate development environment manager that simplifies your Docker-based development workflow. Devbox automates the setup and management of your development containers, SSL certificates, and project configurations.

What is Devbox? Devbox is a command-line tool that creates and manages a complete development environment using Docker containers. It handles PHP, MySQL, Nginx, DNS, and email testing services automatically.

Installation

Getting started with Devbox is simple. Follow these steps to install and configure your development environment.

Prerequisites

  • Docker installed and running
  • macOS or Linux operating system
  • Administrative privileges for binary installation
  • GitHub account (for container registry access)

Download and Install

# Download the latest release
curl -L -o devbox https://github.com/aliasproject/devbox/releases/latest/download/devbox

# Make it executable
chmod +x devbox

# Run the installer
./devbox
Note: On first run, Devbox will automatically install itself to /usr/local/bin/devbox and may prompt for your password.

Quick Start

Get up and running with Devbox in under 5 minutes.

Step 1: Initial Setup

# Run devbox for the first time
devbox

# This will:
# - Install the binary to /usr/local/bin
# - Create ~/.devbox configuration directory
# - Prompt for project directory selection
# - Ask for PHP and MySQL versions
# - Set up GitHub authentication
# - Create Docker Compose configuration
# - Start all containers

Step 2: Verify Installation

# Check installation status
devbox status

# View running containers
devbox ps

Step 3: Access Your Projects

Navigate to any project within your configured project directory and run Devbox commands: 

# From any project subdirectory
cd /path/to/your/projects/myproject
devbox up
devbox logs nginx
Success! Your development environment is now ready. Projects will be automatically available at https://myproject.test

Environment Setup

Configure your development environment with different PHP and MySQL versions.

Supported Versions

PHP Versions

  • PHP 8.2 (default)
  • PHP 8.1
  • PHP 8.0

MySQL Versions

  • MySQL 8.0 (default)
  • MySQL 5.7

Environment Variables

Devbox stores configuration in ~/.devbox/env_vars: 

# Project root directory
DEVBOX_PROJECT_ROOT=/path/to/your/projects

# PHP version
PHP_VERSION=8.2

# MySQL version
MYSQL_SERVER=8.0

SSL Setup

Devbox automatically generates SSL certificates for your local development domains.

Automatic Certificate Generation

When you start Devbox, the Watchman service automatically:

  • Scans your project directory
  • Generates SSL certificates for each project
  • Creates virtual hosts for Nginx
  • Sets up .test domain routing

Trusting Certificates

Important: You'll need to trust the Certificate Authority in your browser to avoid SSL warnings. Devbox will guide you through this process during installation.

Certificate Locations

# CA Certificate
~/.devbox/certs/AliasProjectCASelfSigned.pem

# Project-specific certificates
~/.devbox/certs/projectname.test.crt
~/.devbox/certs/projectname.test.key

GitHub Authentication

Devbox requires GitHub authentication to pull container images from GitHub Container Registry.

OAuth Device Flow

During installation, Devbox will guide you through GitHub OAuth authentication:

  1. Devbox requests a device code from GitHub
  2. You visit the provided URL and enter the user code
  3. Authorize the application in your browser
  4. Devbox receives the access token automatically

Manual Token Setup

If you prefer, you can provide a GitHub token manually: 

# Create a Personal Access Token at:
# https://github.com/settings/tokens

# Run devbox and select manual token entry
devbox
Token Permissions: Your GitHub token needs read:packages permission to pull container images.

Troubleshooting

Common issues and their solutions.

Docker Not Running

Error: Docker is not installed or not running

Solution: Ensure Docker Desktop is installed and running before using Devbox.

Permission Denied

Error: Permission denied installing to /usr/local/bin

Solution: Devbox will automatically use sudo when needed. Enter your password when prompted.

Container Pull Failures

Error: Failed to pull image from ghcr.io

Solution: Check your GitHub authentication with devbox status and re-authenticate if needed.

Project Not Found

Error: You must be inside a project directory

Solution: Navigate to a directory within your configured project root directory.

SSL Certificate Issues

If you're seeing SSL warnings in your browser:

  1. Check if Watchman is healthy: devbox status
  2. Verify certificate exists: ls ~/.devbox/certs/
  3. Trust the CA certificate in your browser/system
  4. Restart containers: devbox restart

Reset Installation

To completely reset your Devbox installation:

# Stop all containers
devbox down

# Remove configuration
rm -rf ~/.devbox

# Remove binary
sudo rm /usr/local/bin/devbox

# Reinstall
./devbox
