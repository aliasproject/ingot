Alios CLI Documentation

Alios CLI (alios) is the local development environment manager for Alios, the cloud infrastructure and application management platform. It automates the setup of per-project Docker containers, SSL certificates, and a reverse proxy so your local PHP projects run the same way they will once deployed to Alios.

What is Alios CLI? Alios CLI is a command-line tool that creates and manages a complete local development environment using Docker containers - PHP (FrankenPHP), a Caddy reverse proxy, DNS for .test domains, MySQL/PostgreSQL, and Mailpit for email testing. It has no server component and no local config files: every command shells out to Docker on your machine, and all state lives in environment variables or Docker container labels.

Installation

Getting started with Alios CLI is simple. Follow these steps to install and configure your development environment.

Prerequisites

  • Docker installed and running
  • macOS or Linux operating system
  • Administrative privileges for binary installation
  • GitHub account (for container registry access)

Download and Install

# Download the latest release
curl -L -o alios https://github.com/aliasproject/alios-cli/releases/latest/download/alios

# Make it executable
chmod +x alios

# Run the installer
./alios
Note: On first run, Alios CLI will automatically install itself to /usr/local/bin/alios and may prompt for your password.

Quick Start

Get up and running with Alios CLI in under 5 minutes.

Step 1: Initial Setup

# Run alios for the first time
./alios

# This will:
# - Install the binary to /usr/local/bin
# - Optionally configure a database service
# - Set up GitHub authentication
# - Start the global services (DNS, Caddy, Mailpit)

Step 2: Verify Installation

# Check installation and service status
alios status

Step 3: Start a Project

Navigate into any project directory and run: 

cd /path/to/your/project
alios start

On the first alios start for a project, you'll be asked for a PHP version and server root - and, if a Dockerfile is present, how you'd like the image built (see Image Selection). None of this is asked again on later starts.

Success! Your project is now available at https://myproject.test

Basic Commands

Learn the essential Alios CLI commands for daily development.

Version and Help

# Show version
alios --version
alios -v

# Show help
alios --help
alios help

Installation Management

# Show complete system status
alios status

# Check for and install updates
alios check-update
alios update
alios update --force

Project Commands

Commands you run from inside a project directory - each acts on the one project container for the current working directory.

Lifecycle

alios start              # Start (or create) the project container
alios start 8.2          # Start with a specific PHP version
alios stop                # Stop the project container
alios restart              # Restart the project container
alios remove               # Remove the project container (alios rm)
alios status                # Show detailed status for this project
alios list                  # List every Alios-managed project (alios ls)

Changing Configuration

alios php 8.2              # Change PHP version (recreates the container)
alios server-root public   # Change the server root directory

Logs, Exec, and Shell

alios logs

alios exec composer install
alios exec npm run dev

alios shell                # Open a shell as your host user
alios shell --user=root    # Open a shell as root

Global Services

DNS, Caddy (the reverse proxy), Mailpit, and any configured databases are shared across every project and managed as one group. 

alios global start
alios global stop
alios global restart
alios global status

Pause & Resume

Stop every project and global-service container at once to free up CPU and RAM, then bring back exactly what was running - no need to remember which projects you had started. 

alios pause    # Stop everything, remembering what was running
alios resume   # Restore exactly that set

Database Commands

alios database add
alios database remove
alios database list

MySQL databases are created with an empty root password. PostgreSQL databases are created with user alios, password alios, and database alios.

Environment Setup

Alios CLI has no local config file - every setting is either an environment variable or a Docker container label. Set the variables below however you normally manage your shell environment.

Environment Variables

GITHUB_TOKEN                  # GitHub token for pulling private images
ALIOS_DEFAULT_PHP_VERSION     # Default PHP version for new projects
ALIOS_HOST_IP                 # Override auto-detected host IP
ALIOS_DNS_PORT                # DNS listener port (default: 53)
ALIOS_ENABLE_SSL              # Enable/disable SSL setup (default: true)
ALIOS_ENABLE_DNS              # Enable/disable DNS setup (default: true)
ALIOS_AUTO_START_GLOBAL       # Auto-start global services (default: true)

SSL Setup

Alios CLI automatically generates a CA certificate and per-project certificates for your local .test domains.

Why self-signed? .test is an IANA-reserved TLD that is never publicly resolvable, so a real certificate authority like Let's Encrypt has no way to verify domain ownership for it. Alios CLI generates its own CA and trusts it locally instead.

How It Works

The CA certificate and every project's certificate/key are generated by a dedicated openssl image and stored in the alios_certs Docker volume - not on your host filesystem. Each project's Caddy vhost configuration is written to the alios_vhosts volume and reloaded automatically, so certificates and routing survive the Caddy container being recreated.

Trusting the CA Certificate

alios cert install    # Install the CA into your system trust store
alios cert verify     # Check whether it's installed
alios cert debug      # Detailed certificate/Caddy diagnostics
alios cert repair     # Regenerate vhosts and restart Caddy
Important: You'll need to trust the CA certificate to avoid browser SSL warnings - alios cert install handles this for you.

Image Selection

When you start a project for the first time, Alios CLI checks the project root for a Dockerfile. This mirrors the same prebuilt-vs-custom choice production Alios makes when deploying a site, so your local environment can match whatever you'll actually run.

  • No Dockerfile found - Alios CLI uses its prebuilt PHP image for the selected version.
  • Dockerfile found - you're asked whether to build from it, use the prebuilt image anyway, or pull a different image entirely.

This choice is made once, at first start, and stored on the project container's labels - it isn't asked again on later starts.

WordPress Projects

If wp-config.php or wp-load.php is found in the project root (covering both stock WordPress and Bedrock-style layouts), Alios CLI automatically selects a WordPress-optimized PHP image instead of prompting you:

  • Extra extensions WordPress needs (mysqli, gd, exif, redis, igbinary, imagick, soap)
  • The same production hardening (blocked execution paths, denied file extensions) used on Alios
  • Live-reload opcache settings and dev tooling (git, npm) for local iteration

GitHub Authentication

Alios CLI requires GitHub authentication to pull container images from GitHub Container Registry.

OAuth Device Flow

During installation, Alios CLI will guide you through GitHub OAuth authentication:

  1. Alios CLI requests a device code from GitHub
  2. You visit the provided URL and enter the user code
  3. Authorize the application in your browser
  4. Alios CLI receives the access token automatically

Personal Access Token or gh CLI

If you prefer, provide a GitHub Personal Access Token directly, or let Alios CLI delegate to an existing gh CLI login: 

# Create a Personal Access Token at:
# https://github.com/settings/tokens

alios github-auth
Token Permissions: Your GitHub token needs read:packages permission to pull container images.

Troubleshooting

Common issues and their solutions.

Docker Not Running

Error: Docker is not installed or not running

Solution: Ensure Docker is installed and running before using Alios CLI.

Permission Denied

Error: Permission denied installing to /usr/local/bin

Solution: Alios CLI will automatically use sudo when needed. Enter your password when prompted.

Container Pull Failures

Error: Failed to pull image from ghcr.io

Solution: Check your GitHub authentication with alios status and re-authenticate with alios github-auth if needed.

Project Not Found

[INFO] No alios project found in this directory

Solution: Run alios init (or alios start, which does the same thing) from inside your project's directory.

SSL Certificate Issues

If you're seeing SSL warnings in your browser:

  1. Check that Caddy is running: alios global status
  2. Verify the CA certificate is installed: alios cert verify
  3. Regenerate vhosts and restart Caddy: alios cert repair

Reset Installation

To completely reset your Alios CLI installation:

# Stop everything
alios global stop

# Remove all Alios CLI state (certs, vhosts, pause state, network)
docker volume rm alios_certs alios_vhosts alios_state
docker network rm alios_internal

# Remove the binary
sudo rm /usr/local/bin/alios

# Reinstall
./alios
