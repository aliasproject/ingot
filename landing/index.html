Local development for PHP

Every project gets its own production-like container, with real HTTPS.

FrankenPHP behind a shared Caddy proxy, a trusted certificate on a *.test domain, and projects that sleep when nobody is using them. One binary and Docker. No config files.

shell
1curl -fsSLo ingot
2chmod +x ingot && ./ingot

The first run installs itself to /usr/local/bin/ingot and walks you through setup. Needs Docker; Windows runs it under WSL2. Or build from source →

~/Projects/acme-shop 
$ ingot start

How it works

From the address bar to your code.

Global services are shared by every project. Each project adds one container and one vhost. Every command shells out to Docker on your machine, so there is no server component to run.

Nothing running there? Any other *.test name gets a "No project here" page instead of a connection error.
Your .env stays yours. Ingot never reads it. Set real env vars with ingot env set, the way production does.
Scale to zero

Keep twenty sites set up. Run the two you're using.

A small global service checks each project's network and CPU every 30 seconds. Quiet for 30 minutes means stopped, and the next request starts it again.

shell
1ingot idle # show this project's setting
2ingot idle off # never stop it (queue workers)
3ingot idle 2h # its own timeout
4ingot idle on # back to the default
~/.bashrc
1# default for every project (30m, 2h, or off)
2export INGOT_IDLE_TIMEOUT=1h
3# then apply it
4ingot global restart
Image selection

Build it the way production does.

Pick per project and switch any time with ingot image. No need to remove and recreate the project.

Sharing

Show a client, or your phone, in one command.

ingot share gives the project a public HTTPS URL through a Cloudflare Tunnel. No DNS, certificates or router changes. Add basic auth for anything that isn't throwaway.

shell
1ingot share # public URL
2ingot share --auth demo:secret # behind basic auth
3ingot share list # every active share
4ingot share stop # stop sharing this project
https://<random-words>.trycloudflare.com
Quick tunnels need no account and get a new URL each time. Named tunnels keep a stable hostname. Shared requests carry X-Ingot-Share: 1 so your app can tell them apart.
